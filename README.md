# Getting Started with the Vue Menu Bar Component

This repository contains a quick‑start Vue sample that demonstrates how to integrate and configure the Syncfusion Vue Menu Bar component in a Vue application.

A quick start Vue project that shows how to add a Menu Bar component to a Vue app. This project also includes example code to bind hierarchical data, self‑referential data, and complex data sources to the Menu Bar component.

## Project Overview
The purpose of this project is to help developers understand the basic usage and configuration of the Syncfusion Vue Menu Bar component. It demonstrates how menus can be structured using different data binding approaches to create flexible and dynamic navigation experiences.

## Features
- Integration of Syncfusion Vue Menu Bar component  
- Binding hierarchical and self‑referential data  
- Support for complex data structures  
- Clean and structured menu navigation  

## Prerequisites
Make sure that your development environment meets the following requirements:
- Node.js (latest version recommended)  
- Vue  
- Visual Studio Code  

## Installation and Running the Application

1. Clone the repository and open it in Visual Studio Code.
```bash
git clone https://github.com/SyncfusionExamples/getting-started-with-the-vue-menu-bar-component.git
```
2. Install the required Vue packages using:`npm install`.
3. Run the application using:`npm run dev`.
4. Navigate to `http://localhost:5173/`. The application will automatically reload if you change any of the source files.
5. Run the application and interact with the Menu Bar to observe how different data binding methods affect menu structure and behavior.
